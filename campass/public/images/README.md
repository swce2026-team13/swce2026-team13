# 예시 사진 출처

사용자가 제공한 Figma 파일에서 이미지 레이어 다운로드로 확보한 시연용 사진입니다.

- 파일: https://www.figma.com/design/ktNH70g1zWpBa3tDQKYASe/1
- `bus.jpg`: 출발 위치 사진 확인 / 주변 사진, 노드 `9:15492`.
- `corridor.jpg`: 사진 기반 단계별 안내 / 주변 사진, 노드 `9:15581`.

서경대학교 현장에서 촬영되었다고 검증된 사진이 아닙니다. 현재 UI에는 예시 사진으로 표시합니다. 실제 촬영 자료가 준비되면 지점별 사진으로 교체해야 합니다. 학습 데이터로 자동 전송하거나 학습에 사용하지 않습니다.
