# CAMPASS 캠퍼스 데이터

3D 길찾기 지도와 경로 계산에 쓸 캠퍼스 자료를 한곳에 모은 폴더입니다. 2026-10-18 기준이며, 아래 출처들을 합쳐서 만들었습니다.

## 폴더 구성

| 파일 | 내용 |
| --- | --- |
| `buildings.json` | 건물 13곳: 좌표, 건물 윤곽, 크기·회전 각도, 층 목록(아래 → 위), 엘리베이터 유무, 메모. 윤곽은 학교 캠퍼스맵 화면(카카오맵)과 같은 구도로 맞춤 |
| `links.json` | 건물 사이 연결 27개: 어느 건물 몇 층 ↔ 어느 건물 몇 층, 실내·실외, 확인 상태, 근거 |
| `entrances.json` | 건물 입구, 연결통로, 정문·서문, 버스정류장, 주차장 입구 35곳의 위치. 2115 정류장·정문은 `connectsTo`에 걸어서 이어지는 건물 층과 확인 상태(`connectsStatus`)가 있음 |
| `rooms.tsv` | 호실 1,255개: 건물, 호수, 층, 호실명, 용도 |
| `places.tsv` | 시설·연구소·출입 102곳: 층, 호수, 운영시간, 연락처, 위치 |
| `terrain.json` | 캠퍼스 주변 등고선(5m 간격)과 표고점 |
| `sources/` | 원본 자료 (아래 참고) |

## 좌표

- 모든 위치는 **로컬 미터 좌표 `[동쪽, 북쪽]`** 입니다. 기준점(0, 0)은 한림관입니다(학교 캠퍼스맵 좌표 37.61523, 127.01259).
- three.js로 그릴 때는 `x = 동쪽`, `z = -북쪽`으로 넣으면 지도와 같은 방향이 됩니다.
- 위도·경도가 필요하면 `buildings.json`의 `official`, `entrances.json`·`places.tsv`의 위도·경도를 쓰면 됩니다.

## buildings.json

| 항목 | 뜻 |
| --- | --- |
| `official` | 학교 캠퍼스맵의 건물 좌표 (위도·경도·로컬) |
| `footprint` | 건물 윤곽. `polygon`(꼭짓점), `center`, `lengthM`·`widthM`(긴 변·짧은 변), `longSideAngleDeg`(긴 변 방향, 동쪽 기준 반시계 각도), `source`(어디서 가져왔는지). 수인관은 `approximate: true` |
| `floors` | 실제 층 이름 순서. 4층·13층이 없는 건물이 많고, L층은 실제 층 번호로 넣고 `label`에 "L층"으로 적음 |
| `roomFloors` | 학교 호실 번호로 확인되는 층 (호실이 없는 층은 빠짐) |
| `elevator` | `true` 확인됨 / `null` 모름 |
| `campusMapLevel` | 캠퍼스맵 이미지(두 번째)의 ‘연결층수’ 표기 |
| `sectionElevationDraft` | 3D 시안에 넣었던 단면도 기준층 해발고도. 층 목록이 바뀌기 전 값이라 **참고용** |

**L층 정리 (확인됨)**: 청운관 L층 = 2층, 문예관 L층 = 3층 자리, 유담관 L층 = 6층 자리.

## links.json

| 상태 | 뜻 | 개수 |
| --- | --- | --- |
| 확인 | 현장 메모, 피난안내도, 팀 확인으로 근거 있음 | 10 |
| 확인 필요 | 자료는 있지만 실제로 걸어서 되는지 모름 | 2 |
| 추정 | 근거 약함 (3D 시안의 ‘같은 높이’ 가정 등) | 10 |
| 삭제 | 틀린 것으로 확인됨, 쓰지 않음 | 5 |

확인된 연결 10개:
- 본관 5층 ↔ 한림관 3층 ↔ 은주1관 2층 (같은 높이)
- 한림관 6층 ↔ 은주1관 5층
- 은주1관 5층 → 동쪽 출입구 → 스콘스퀘어 (광장 높이 약 149m)
- 스콘스퀘어 ↔ 혜인관 1층 (같은 높이)
- 북악관 7층 ↔ 문예관 6층
- 은주2관 1층 ↔ 수인관 1층 (실외, 계단 없음. 은주2관 엘리베이터로 1층 → 수인관 앞, 풋살장도 이쪽)
- 본관 1층 ↔ 지하주차장 (2115 정류장 뒤 본관 1층에서 지하통로로. 계단·언덕이 있음)
- 유담관 8층 ↔ 본관 1층 (계단 여부는 모름)
- 혜인관 지하 1층 ↔ 지하주차장 (반층 내려감. 계단이 있음)

**확인된 연결만으로 시연 경로가 이어집니다**: 본관 → 5층 → 한림관 3층 → 6층 → 은주1관 5층 → 스콘스퀘어 → 혜인관 1층 → 3층.
2115 정류장 → 본관 1층, 본관 5층 ↔ 한림관 3층, 한림관 6층 ↔ 은주1관 5층, 은주1관 5층 → 스콘스퀘어, 스콘스퀘어 ↔ 혜인관 1층은 계단 없이 이어집니다(팀 확인 10/24). 그래서 이 길은 엘리베이터로 계단 없이 갈 수 있습니다.
본관 1층 → 지하주차장 → 혜인관 지하 1층으로 가는 지하통로 길도 이어지지만 계단이 있어 엘리베이터 길로는 쓰지 않습니다.
북악관·문예관·유담관·청운관·대일관·상승관, 은주2관·수인관 쪽은 아직 이 경로와 이어지지 않습니다 (아래 남은 확인 2·5, 실외 입구 층).

`extraNodes`에 건물이 아닌 지점 두 곳(스콘스퀘어, 지하주차장)이 있습니다. 스콘스퀘어는 `polygon`(광장 영역, 약 7,900m²)과 중심 `approxLocal`이 있습니다. 캠퍼스맵 이미지의 흰 점선은 실외 언덕길이라 연결에서 뺐습니다.

## 남은 확인 (현장)

1. 지하주차장: 은주1관 3층 · 청운관 지하1층이 주차장 안에서 걸어서 이어지는지 (본관 1층 · 혜인관 지하1층은 확인됨)
2. 스콘스퀘어: 광장에서 대일관·상승관·청운관·은주2관 각각 몇 층으로 들어가는지 (은주1관 5층 · 혜인관 1층은 확인됨). 은주1관 5층 출입구가 계단 없이 이어지는지
3. 유담관 버스정류장 출구: 7층(캠퍼스맵)인지 9층(피난안내도)인지
4. 은주2관: 기숙사 층이 어디인지(엘리베이터로 지나가는 건 가능, 목적지·경유지로는 안 씀), 2~4·6층 구성, 7층이 있는지 (학교 자료끼리 다름)
5. 추정 통로: 은주1관 ↔ 은주2관(1·3·5층), 본관 ↔ 북악관, 유담관 ↔ 본관
6. 수인관 2·3층이 있는지와 실제 건물 윤곽(지금은 풋살장 영역으로 대신), 상승관 층수, 청운관 엘리베이터
7. 입구 35곳이 각각 몇 층인지 (건물 사이 실외 이동을 경로에 넣으려면 필요)
8. 단면도 기준층 해발고도 (수치지형도 등고선으로 대략 검증 가능)

## 출처와 주의

- **학교 캠퍼스맵 데이터**: [skuniv.ac.kr/campus-map](https://www.skuniv.ac.kr/campus-map) 페이지가 불러오는 건물·호실·장소 데이터 (2026-10-17 수집). 학교 공개 자료지만, 교수 연구실 이름처럼 사람 이름이 들어 있으니 앱에 그대로 넣을지는 학교에 한번 확인하세요.
- **크리에이티브센터**: 학교 캠퍼스맵 데이터에 없어 수치지형도 건물(이름 칸 '공연연실습소', 4층) 윤곽을 썼고, 위치는 일러스트 캠퍼스맵 기준입니다. 층은 추정값입니다.
- **수치지형도**: 건물 이름과 층수 표기가 오래되거나 틀린 곳이 있습니다. 본관 = ‘군사학과’, 상승관 = ‘제206학생군사교육단’, 은주1·2관 = ‘대일관광디자인고등학교’(한 윤곽), 한림관은 이름 없음. 수인관은 윤곽이 없습니다.
- **건물 윤곽 맞춤 (10/18)**: 학교 캠퍼스맵 화면(카카오맵) 스크린샷의 건물 좌표 점 12개로 지도를 데이터 좌표에 맞췄습니다(오차 0.5m 이내). 그 지도 경계를 기준으로 은주1관·은주2관을 나누고, 대일관 윤곽 동쪽 끝을 상승관으로 나눴습니다. 스콘스퀘어(광장)와 수인관(풋살장 영역)은 그 지도에서 영역을 따왔습니다. 수치지형도의 유담관 서쪽 긴 건물은 지금 지도에 없어 뺐습니다. 맞춘 결과는 `figures/map-overlay.png`에서 볼 수 있습니다.
- **층(rooms.tsv)**: 호수 앞자리로 계산했습니다(101 → 1층, 1201 → 12층, B101 → 지하1층). 호수가 비었거나 규칙에서 벗어난 번호(유담관 ‘유)A-1’, 본관 6122 등)는 층을 비워 두었습니다.
