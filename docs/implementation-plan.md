# 구현 순서 — 2026-10-08

사용자 추가 요구를 승인된 구현 범위에 반영한다. 학교는 서경대학교, 글꼴은 Noto Sans KR, 사진 인식 모델은 추후 직접 촬영한 사진으로 학습하며 외부 API를 연결한다. 운영환경은 배포하지 않고 가격과 제약을 비교한다.

1. 공식 건물·장소 정보에 출처를 붙이고, 미검증 실내 경로와 분리한다.
2. Node.js 기본 테스트 러너로 검색·경로·영구저장·중복집계·세션 접근·AI 미설정 동작을 먼저 검증한다.
3. SQLite 저장 계층, 경로 서비스, 요청 검증, 세션 쿠키와 관리자 인증, 공급자 어댑터 API를 구현한다.
4. 12개 화면과 모바일 디자인, 지도·검색·업로드·진행·복구·피드백을 연결한다.
5. 빌드·린트·통합 테스트 및 브라우저 흐름/디자인 점검 후 독립 코드 리뷰를 수행한다.
6. `백엔드 구현.md`에 실제 완료 범위, 데이터 출처, 스키마, API, 예제, 설정, 테스트 결과, 한계와 가격 비교를 작성한다.

계획 스킬 writing-plans는 설치된 스킬 파일 검색에서 발견되지 않아 이 문서로 구현 순서를 관리한다. 앱 기능과 관계없는 Git 커밋/배포/계정 생성은 수행하지 않는다.
